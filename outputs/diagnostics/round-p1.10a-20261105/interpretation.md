## 0. 冻结与实现

`OxygenMixingModel` 缺省 `instant` → 不进入混合分支，与 P1.9-A 基线逐位一致（第 1 项检查）。非 instant 时入口 O2 作不反应旁流，按累计分数 `F(z)` 逐格并入；源项进入 `gas_src[0]`，因此气相 O2 平衡、燃烧区判据与元素守恒都自动看到本格并入的 O2——这正是卡面「入口反应流 + 本格并入的 O2」。速率式、限幅、判据阈值、求解器容差未改。

两处实现细节按卡面要求在 `interpretation` 中写明：

1. **exponential 的阶跃分量**。`F` 在 `L_mix` 左极限为 `1−exp(−3)`，右侧取 1，阶跃分量 `exp(−3)` 落在下游边界恰为 `L_mix` 的那一格。该格的**总源项**是「连续部分 + 阶跃」= `exp(−3·(1−dz0/L_mix))`，`dz0=L_mix/40` 时为 **5.37%**，**不是** 4.98%。卡面检查 4 的 `exp(−3)` 只能读作阶跃分量；把它当成边界格总源项会使 Σ 源项只到 95.02%、破坏守恒。单元检查 4 同列这两个量。
2. **残差缩放基准**。`instant` 下 O2 在 `inlet.gas_moles` 里，mixing 下不在；若仍按 `inlet.total_gas_moles` 定标，同一套方程会得到不同的 `ref_f`，实测残差同比放大 **4.94 倍**、出口温度漂移 0.018 K。已把旁流计入 `ref_f`（`instant` 下旁流恒为 0，返回值与旧代码逐位相同），并把首格的旁流份额计入初值，使两种口径走同一条求解路径。修后同一状态上的残差差为 **0.0**、`L_mix`=0.25 与 instant 的出口差为 **0.0**。

### 为什么 M1 全部不通过：分布式 O2 把火焰稀释掉了

点火在本模型里是**逐格热平衡**，不是累积过程。首格可用的反应热只来自**本格并入的那一份 O2**，而它必须同时把**整股固体**（`W_dry` ≈ 19 kg/s，`cp_char` = 1300 J/kg/K → 固体热容流率 ≈ 25 kW/K）加热到点火温度。因此首格 O2 份额直接决定单格可升温量：

| 首格 O2 份额 | 本格 O2（mol/s） | 约合反应热 | 单格可升温 |
|---|---|---|---|
| 100.0% | 465.5 | ≈102.9 MW | ≈4122 K |
| 50.0% | 232.7 | ≈51.4 MW | ≈2061 K |
| 20.0% | 93.1 | ≈20.6 MW | ≈824 K |
| 10.0% | 46.5 | ≈10.3 MW | ≈412 K |
| 5.0% | 23.3 | ≈5.1 MW | ≈206 K |
| 2.5% | 11.6 | ≈2.6 MW | ≈103 K |

把份额推到 5% 与 2.5%（= 卡面 M1 的 `L_mix/20`、`L_mix/40`），单格可升温降到数百 K 以下，低于点火所需，于是**不存在点火根**：求解器要么报 `no_root`，要么停在温度下界 300 K（熄火解）。后者尤其危险——`dz0 = L_mix/10`（10%）时确有几窗返回 `completed` 但 `cell0 T = 300 K`，若不拦截会被 M1 当成收敛点。本轮的 `_branch_status` 已把「完成但温度触界」标为 `cold_branch_T_at_lower_bound`，不计入收敛。

逐窗实测（固定 `L_mix` = 1 m，只改 `dz0`；9 窗）：

|---|---|---|---|
| 2.5% | 0 | 0 | 9 |
| 5.0% | 0 | 0 | 9 |
| 10.0% | 3 | 3 | 3 |
| 20.0% | 0 | 9 | 0 |
| 50.0% | 0 | 9 | 0 |
| 100.0% | 0 | 9 | 0 |

| 首格 O2 份额 | min | median | max |
|---|---|---|---|
| 2.5% | 300.0 | 300.0 | 300.0 |
| 5.0% | 300.0 | 300.0 | 300.0 |
| 10.0% | 300.0 | 300.0 | 334.9 |

**结论**：阈值在 10% 与 20% 之间——20% 份额 9/9 窗点火（cell 0 中位 736 K），10% 只有 3/9 窗返回完成且温度 ≤335 K，5% 与 2.5% 全部 `no_root`。卡面 M1 网格（`L_mix/20`、`L_mix/40`）整体落在熄火区，因此 **M1 无法在本模型的这一实现下评估**，`n_adm` = 0。

**锚点是支持性证据，但不是充分证明。** 同一混合模型在 Fortran 几何上（煤流小 3 个数量级）对 `L_mix` = 0.5、0.75 m 是收敛的，`dz0 = L_mix/20`（同为 5% 份额）仍能点火。这与「单格放热 ÷ 整股固体热容流率」的机理一致，因此排除了「装置工况下单纯是代码写错」这一解释；但锚点与装置算例的**几何、煤流、氧量同时不同**，它不是受控对照，**不能据此断言机理已被完全确定**——求解器行为（初值路径、严格根判据）与实现细节仍可能是贡献项。本报告把结论限定为：在本模型这一实现下，稀释型混合使装置工况无法点火；更细的归因需要受控实验（固定煤流、只改份额）另行确认。

### 这不是调参问题，是「稀释」与「点火」的冲突

卡面的混合模型是**把 O2 摊薄到 `L_mix` 上**。摊薄降低了每一格的可燃比与放热集中度，而一维模型里点火恰恰要求某一格内放热足以把整股固体加热。真实烧嘴近场有**局部富氧**的火焰锋（射流卷吸造成空间上的化学计量分布），一维稀释并不产生这种局部富氧，只是把整体化学计量拉向贫燃。所以「单参数混合长度」在这一实现下不是「把火焰拉长」，而是「把火焰熄掉」。

**这对主线的含义**：G4 提出的「烧嘴近场混合状态」若要作为可解释调节量，需要的不是稀释型混合长度，而是能在**单格内**保留局部富氧/高分压 O2 的描述（例如把 O2 分配与射流结构耦合、或在首格保留一个未混合核）。卡面这一版不能直接支撑「混合长度是调节量」的结论。
