# P2.5-D 装置组成偏还原的成因诊断 — 判读

Status: `EXECUTED — offline analysis only`（无求解器调用）

依据：论文仓任务卡 `data-side-handoff-p2.5d-20261120.md`；输入 P2.2-A `baseline_142.csv`（142 窗，全部 completed）与 P2.2-D `reconciled_windows.csv`（`combination=S1-C-m`）。

## 结论摘要

1. **在现有数据下，H-A 与 H-B 分不开。** 判别所需的两项——装置侧实际入炉水量、反应器出口湿气 H₂O 分率——都没有在**所需位置**上的独立测量。R0 表逐项给出：3 项 yes、3 项 partial、1 项 derived、1 项 conditional、4 项 no。洗涤塔出口确实有**湿流量通道**（四阶段分钟级近全覆盖），但由它得到的水分率是 `dry = wet*(1−Psat/P)` 的**回算**，恒等于饱和假设本身，不是独立测量；缺口是「**缺所需位置**」，不是「缺湿流量通道」，更不能写成「已有独立 H₂O 测量」。
2. **单 ξ 共同位移在 P2 与全部窗相容，在 P1/P3 约一半窗超阈值，在 P4 全部超阈值。**P2 只能说「与单一移动相容」，不是「证明够用」；P4 的阶段中位 χ² 已超阈值，单一移动解释不了该阶段的缺口。
3. **R3 给不出与 H-A 一致的方向（P1/P3 反而相反）。** ρ(ξ, T_out) 在 P1（−0.65）、P3（−0.74）显著为负，P2 无信号（−0.24, p=0.12），仅 P4 为正（+0.67）。按卡片预声明判据，这不是「与 H-A 方向一致」。**但第 2 种结果记为「未获支持」，不是「被排除」**：ξ 按定义是模型与装置 CO₂ 的残差，它跟模型 CO₂（ρ=−0.70/−0.33/−0.80/−0.68）而非装置 CO₂（0.21/0.08/0.25/0.89）；P1–P3 内模型 CO₂ 与 T_out 强同向（0.95/0.97/0.95），机械地把 ξ 压成负相关。该检验近似在测模型内部协方差，因此不构成对 H-A 的反证。（原字面判据的结果见 VERDICT/outcome_2_predeclared_literal，仅作历史记录。）
4. **R4 的 T_eq 不可引用。** 出口水情景从 5% 扫到 20%，T_eq 漂移远超 150 K，按预声明判据记为「无信息」。R4 不参与 H-A 判定。
5. 因此本卡属于第 3 种结果：**如实报「分不开」**，最终产出是所需观测清单（§R0）与 P4 的阶段级不相容。

H-A 的方向性预测是 **ρ > 0**（出口越热 → K_WGS 越小 → 需要更大的正向前移）。实测 P1、P3 显著为负，全样本也为负（−0.40）。归一的 ξ/dry 与 T_out 相关在 P1 减弱到 −0.35（p=0.03），P3 仍为 −0.65，说明负号不是单纯由 dry 的窗口差异造成。按预声明判据，这是「与 H-A 方向相反」，不是「不矛盾」。

一个与判据无关的观察（诊断，不是新判据）：逐窗反解的 ξ 主要跟随**模型** CO₂ 的窗口间起伏（ρ(ξ, model_CO₂) = -0.70 / -0.33 / -0.80 / -0.68），而不是装置 CO₂（ρ = 0.21 / 0.08 / 0.25 / 0.89，只有 P4 例外）；模型 CO₂ 的 CV（0.04–0.18）也远大于 T_out（0.012–0.039）。在 P1–P3 内，模型 CO₂ 与 T_out 同向（ρ = 0.95 / 0.97 / 0.95），于是 ξ 被压成负相关；P4 反过来（ρ = -0.43），ξ 与 T_out 才成正相关。也就是说，R3 的符号主要由阶段内模型自身的 CO₂–T_out 关系决定，不是由装置侧决定——这正是卡片说这个检验很弱的原因。本卡不据此把负号读成机理证据，只把它如实记为「与 H-A 方向相反」。

P4 的方向虽然一致（ρ = +0.67），但同一阶段的单一移动拟合最差：ξ̂ 中位 97.1 mol/s，比逐窗反解中位 113.6 低约 15%，中位 χ² = 18.6，17/17 窗超阈值。方向一致出现在单移动假设被拒绝的阶段，不能当作对 H-A 的支持。

## 单元检查

- **U1**：逐窗中位 ξ 与 P2.2-A 阶段常数的差，最大偏离卡面已知值 0.0049 个百分点（容差 0.05）。U1 是诊断项，不触发停止。
- **U2**：3 窗独立重算，最大绝对差 1.42e-14（容差 1e-9）。
- **U2b**：`dry` 与各 `F_i` 同步 ±4%，`ξ̂/dry` 最大偏差 8.33e-17、χ² 最大偏差 2.18e-13（容差 1e-9），通过。
- **U3**：`correlations.csv` 每个检验都带 `n` 与 `n_missing`；142 窗全部可解，无缺失。

## 判定

**第 3 种：分不开。** 理由：

1. R0 显示判别 H-A/H-B 的两个关键量（入炉水量、反应器出口 H₂O）在现有数据下不可辨识；洗涤塔出口的湿流量通道存在且覆盖近全时段，但由此回算的水分率恒等于饱和假设，不是独立测量——缺口在位置，不在通道。
2. R3 给不出与 H-A 一致的方向（P1/P3 反而相反），第 2 种结果因此**未获支持**；但 ξ 与模型 CO₂ 的机械耦合使该检验不构成反证，故**不能**记为「被排除」。
3. R2 是混合的：P2 全部相容，P1/P3 约一半超阈值，P4 全部超阈值。P4 的阶段级结论是第 1 种（不相容，缺口不止一个成分），但不能推广到四阶段。

**不采用第 1 种作为总判定**：卡片没有预声明「阶段是否相容」如何由逐窗计数聚合，P1/P3 的中位 χ² 仍在阈值内；把 P4 的结果推广到全部阶段会超出数据。

## 能确定 / 不能确定

**能确定：**

- 三观测量为干基，现有数据下 `Q_plant` 与反应器出口 H₂O 不可辨识（R0）。
- 单一 WGS 移动在 P2 与全部窗相容；在 P4 与全部 17 窗不相容。
- `ξ̂/dry` 与 χ² 对 `dry` 的同步缩放不变（U2b），R2 的判据不依赖流量规模。
- T_eq 对出口水情景极不稳健，不可引用（R4）。

**不能确定：**

- 缺口是 H-A（缺下游过程）还是 H-B（水基准错），以及 ξ 的物理归属。
- 沿程动力学是否相关（本卡按范围选择不改 WGS 动力学，未检验）。
- P1/P3 那部分超阈值窗是结构差异还是分析仪口径问题（需要独立观测）。

## 所需观测（若要与本卡之外的证据合流）

1. 反应器出口或激冷入口的**湿基** H₂O 测量——现有湿基通道在洗涤塔出口，位置不对；若能把取压/取样点前移到激冷入口，这一项即可闭合。
2. 独立的入炉水测量：逐窗煤水分、激冷水流量、蒸汽流量（当前只有 2% 假设与「无烧嘴蒸汽」的定性确认）。
3. 激冷段/废锅的温度与停留时间剖面，用于判断下游是否真有变换窗口。
4. 刘文或其他文献的湿气数据作交叉核对（现有对照表只有干基）。
5. 若要检验沿程动力学，需另立 WGS 速率倍数敏感性实验（本卡不做）。
